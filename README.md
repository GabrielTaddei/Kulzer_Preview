# Kulzer Brasil — Preview de redesign

Proposta de redesign da home de [kulzer.com.br](https://kulzer.com.br/pt/pt/inicio/inicio.html), produzida pela Thoth Gathering Solutions.

- `index.html` — página única e independente (HTML + CSS + JS, sem build).
- Para visualizar online: **Settings → Pages → Deploy from a branch → `main` / root**. A página fica em `https://gabrieltaddei.github.io/Kulzer_Preview/`.
- Para visualizar localmente: abra `index.html` no navegador.

Observações: logo em texto provisório (trocar pelo SVG oficial) e marcadores `[FOTO …]` onde entram imagens de produto. Os efeitos de rolagem usam CSS scroll-driven animations (Chrome, Edge e Safari recentes).
