# Kulzer Brasil — Preview de redesign

Proposta de nova home para [kulzer.com.br](https://kulzer.com.br/pt/pt/inicio/inicio.html), produzida pela Thoth Gathering Solutions. Segue o KV oficial da Kulzer (logo, verde-limão `#B1C127`, cinza `#575756`, Roboto e Roboto Condensed, globos e fotos oficiais) com experiência moderna.

- `index.html` — página única e independente (HTML + CSS + JS, sem build). Logo e imagens são carregados diretamente de kulzer.com.br.
- Para visualizar online: **Settings → Pages → Deploy from a branch → `main` / root**. A página fica em `https://gabrieltaddei.github.io/Kulzer_Preview/`.
- Para visualizar localmente: abra `index.html` no navegador.
